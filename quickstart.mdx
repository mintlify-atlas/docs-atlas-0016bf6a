title: "Get up and running with SysWatch in minutes"
description: "Launch SysWatch, navigate twelve tabs with keyboard shortcuts, and use the Insights anomaly badge to find problems fast — all in your first session."
---

SysWatch starts in under a second and requires no configuration. This page walks you through launching the tool, choosing a tick rate, navigating the twelve tabs, and reading the keyboard reference — so you can get to diagnosing fast.

<Steps>
  <Step title="Build and install">
    If you have not built SysWatch yet, clone the repository and run a release build:

    ```bash
    git clone https://github.com/matthart1983/syswatch.git && cd syswatch
    cargo build --release
    ```

    See [Installation](/installation) for prerequisites and optional features.
  </Step>

  <Step title="Launch SysWatch">
    Run the binary. SysWatch opens on the Overview tab at a 1 Hz refresh rate by default.

    ```bash
    ./target/release/syswatch
    ```

    If you copied the binary to your `PATH`, run `syswatch` directly.
  </Step>

  <Step title="Adjust the tick rate (optional)">
    The `--tick` flag controls the fast-loop polling interval in milliseconds. The default is 1000 ms (1 Hz). Pass a lower value for faster updates — for example, 500 ms for 2 Hz:

    ```bash
    syswatch --tick 500
    ```

    Higher tick rates increase CPU usage slightly. At idle, SysWatch targets under 0.5% CPU at 1 Hz.
  </Step>

  <Step title="Start on a specific tab (optional)">
    Use `--tab` to open SysWatch directly on the tab you need. Valid names are: `overview`, `cpu`, `memory`, `disks`, `fs`, `procs`, `gpu`, `power`, `services`, `net`, `timeline`, `insights`.

    ```bash
    syswatch --tab procs
    ```

    This is useful when you already know which subsystem to investigate.
  </Step>

  <Step title="Navigate the twelve tabs">
    Use number keys and symbols to jump directly to any tab. Use `Tab` and `Shift-Tab` to cycle through them one at a time.

    | Key | Tab |
    |---|---|
    | `1` | Overview |
    | `2` | CPU |
    | `3` | Memory |
    | `4` | Disks |
    | `5` | Filesystems |
    | `6` | Procs |
    | `7` | GPU |
    | `8` | Power |
    | `9` | Services |
    | `0` | Net |
    | `-` | Timeline |
    | `+` | Insights |
  </Step>

  <Step title="Check the Insights tab">
    Press `+` to open the Insights tab. If SysWatch has detected any anomalies during your session — swap thrash, runaway processes, disk pressure, zombie parties, high load, memory pressure — they appear here as plain-English cards, each with a severity level (WARN or CRIT) and a suggested tab to investigate.

    <Tip>
      The `[+]` badge in the tab bar shows the count of active anomalies. It is visible from every other tab, so you never have to leave your current view to know whether something needs attention.
    </Tip>
  </Step>
</Steps>

## Full keyboard reference

```text
1 2 3 4 5 6 7 8 9   →  Overview / CPU / Mem / Disks / FS / Procs / GPU / Power / Services
0 - +               →  Net / Timeline / Insights
Tab / Shift-Tab     →  Cycle tabs
↑ / ↓               →  Select row (Procs, Services)
s                   →  Cycle sort (Procs, Services)
← / →               →  Scrub session backward / forward (Timeline)
Home / End          →  Oldest sample / live (Timeline)
p                   →  Pause
q / Ctrl-C          →  Quit
```

The `←` and `→` scrub controls work on **every tab** — not just the Timeline tab. Scrubbing rewinds every panel in the application simultaneously: every tab shows historical state at the scrubbed point in time. Press `End` or repeatedly press `→` to return to live data.
