SysWatch is configured entirely at launch via command-line flags — there is no config file. Two flags control the fast-loop refresh rate and the starting tab. All other behaviour is determined by keyboard interaction at runtime.

## Flags

<ParamField path="--tick" type="integer" default="1000">
  Fast-loop interval in milliseconds. Controls how often SysWatch samples and redraws CPU, memory, processes, network IO, and disk IO. The minimum enforced value is **100 ms** — values below 100 are clamped to 100 at startup.

  Power and Services tabs use a separate slow loop fixed at **5 seconds** regardless of this setting, because their collectors invoke subprocesses (`pmset`, `launchctl`, `systemctl`) that are expensive on macOS.

  Common reference points:

  | `--tick` value | Effective refresh rate |
  |---|---|
  | 500 | 2 Hz |
  | 1000 (default) | 1 Hz |
  | 2000 | 0.5 Hz |
  | 5000 | 0.2 Hz |

  At the default 1 Hz with no GPU or SMART features enabled, SysWatch targets under 0.5% CPU at idle.
</ParamField>

<ParamField path="--tab" type="string">
  Start on a specific tab instead of Overview. Accepts the canonical name (case-insensitive) or the numeric shortcut shown in the tab bar. If the value does not match any known tab, SysWatch falls back to Overview silently.

  Valid values:

  | Name aliases | Tab |
  |---|---|
  | `overview`, `1` | Overview |
  | `cpu`, `2` | CPU |
  | `memory`, `mem`, `3` | Memory |
  | `disks`, `disk`, `4` | Disks |
  | `fs`, `filesystems`, `5` | Filesystems |
  | `procs`, `processes`, `6` | Procs |
  | `gpu`, `7` | GPU |
  | `power`, `8` | Power |
  | `services`, `9` | Services |
  | `net`, `network`, `0` | Net |
  | `timeline`, `-` | Timeline |
  | `insights`, `+` | Insights |
</ParamField>

## Usage examples

```bash
syswatch                       # default 1 Hz tick, Overview tab
syswatch --tick 500            # 2 Hz refresh
syswatch --tick 2000           # 0.5 Hz for lower CPU overhead
syswatch --tab procs           # start on Procs tab
syswatch --tab cpu             # start on CPU tab
syswatch --tick 500 --tab cpu  # 2 Hz, start on CPU
```

## No config file

SysWatch has no configuration file or environment variable support. Every session starts from defaults unless flags are passed. If you use a specific tick rate regularly, wrap the invocation in a shell alias:

```bash
alias sw='syswatch --tick 500 --tab overview'
```
