SysWatch is a read-only, single-host diagnostics tool for macOS and Linux. Open it when something feels off — before you reach for five separate tools. Twelve tabs cover every subsystem on one box: CPU, memory, disks, filesystems, processes, GPU, power, services, networking, plus a session Timeline scrubber and an Insights anomaly engine that surfaces what's wrong in plain English and points you to the right tab.

## What SysWatch replaces

| Tab | Commands it replaces |
|---|---|
| Overview | Dashboard view of all subsystems at a glance |
| CPU | `htop` CPU panel, `top -d`, `mpstat` |
| Memory | `free`, `vm_stat`, `htop` mem panel |
| Disks | `iostat`, `iotop` aggregate |
| Filesystems | `df -h`, `df -i`, `mount` |
| Procs | `htop`, `ps auxf`, `pstree` |
| GPU | `ioreg AGXAccelerator` / `/sys/class/drm` |
| Power | `pmset`, `ioreg AppleSmartBattery` / `/sys/class/power_supply` |
| Services | `launchctl list` / `systemctl list-units` |
| Net | `nettop`, `iftop` |
| Timeline | No equivalent — session log with scrubber |
| Insights | No equivalent — plain-English anomaly cards |

## Get started

<Steps>
  <Step title="Install SysWatch">
    Clone the repository and build with Cargo, or tap the Homebrew formula.

    ```bash
    git clone https://github.com/matthart1983/syswatch.git && cd syswatch
    cargo build --release
    ```
  </Step>
  <Step title="Launch the TUI">
    Run the binary. SysWatch starts on the Overview tab at 1 Hz by default.

    ```bash
    ./target/release/syswatch
    ```
  </Step>
  <Step title="Navigate tabs">
    Press `1`–`9`, `0`, `-`, or `+` to jump to any of the twelve tabs. Use `Tab` and `Shift-Tab` to cycle through them sequentially.
  </Step>
  <Step title="Check the Insights tab">
    Press `+` to open Insights. Any active anomaly cards show severity (WARN/CRIT), a plain-English title, and a suggested tab to investigate further.
  </Step>
</Steps>
